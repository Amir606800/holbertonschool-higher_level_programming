Printing sorted lists
-----------------------------

First we should create the inherited list
    >>> MyList = __import__('1-my_list').MyList


Then write the first test situation
    >>> my_list = MyList()
    >>> my_list += [0]
    >>> my_list.append(4)
    >>> my_list.append(1)
    >>> my_list.append(10)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> my_list.print_sorted()
    [0, 1, 3, 4, 5, 10]

Now the second test case
    >>> my_list = MyList()
    >>> my_list += [0]
    >>> my_list.append(2)
    >>> my_list.append(5)
    >>> my_list.append(6)
    >>> my_list.append(8)
    >>> my_list.append(10)
    >>> my_list.print_sorted()
    [0, 2, 5, 6, 8, 10]

The Third test case
    >>> my_list = MyList()
    >>> my_list += [0]
    >>> my_list.append(4)
    >>> my_list.append(-1)
    >>> my_list.append(-10)
    >>> my_list.append(3)
    >>> my_list.append(7)
    >>> my_list.print_sorted()
    [-10, -1, 0, 3, 4, 7]

The fourth test case
    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

The new list check test
    >>> my_list = MyList()
    >>> my_list.append(7)
    >>> my_list.append(1)
    >>> my_list.append(2)
    >>> my_list.print_sorted()
    [1, 2, 7]
    >>> my_list
    [7, 1, 2]
